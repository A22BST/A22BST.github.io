# Ahmad Mohammad: portfolio site

Static site (plain HTML/CSS, no build step) for GitHub Pages.

```
index.html              overview (sheet 00)
projects/*.html         one page per project (sheets 01-08)
assets/css/style.css    all styling, light + dark theme
assets/js/site.js       theme toggle + "copy email" button
assets/img/             optimised WebP images (full + -sm sizes)
assets/video/           two short muted clips from the thesis defence
cv.pdf                  general CV (no phone number)
.nojekyll               tells GitHub Pages to serve files as-is
```

All links are relative, so the site works both from a local folder/server and on GitHub Pages.

## Publish on GitHub Pages

The steps assume the GitHub username **A22BST** (taken from the local git config).
If yours is different, replace `A22BST` everywhere below, and also in
`portfolio/cv_general.tex` (the portfolio link on the CV), then rebuild the CV.

1. On github.com, create a **new public repository** named exactly
   `A22BST.github.io`. Don't add a README, .gitignore or licence.
2. In a terminal, from this `portfolio-site` folder:

   ```bash
   git init
   git add .
   git commit -m "Portfolio site"
   git branch -M main
   git remote add origin https://github.com/A22BST/A22BST.github.io.git
   git push -u origin main
   ```

   (Or use GitHub Desktop: *File → Add local repository* → this folder → *Publish repository*,
   named `A22BST.github.io`, untick "Keep this code private".)
3. In the repo on github.com: **Settings → Pages → Build and deployment →
   Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save**.
4. After a minute or two the site is live at **https://a22bst.github.io/**.

If you'd rather use a repo with another name (e.g. `portfolio`), the same steps
work and the URL becomes `https://a22bst.github.io/portfolio/`.

## Preview locally

```bash
python -m http.server 8765
```

Then open http://localhost:8765 in a browser.

## Editing

The HTML is generated by `../portfolio/build_site.py` (all the text lives there).
Edit the text in that file and run `python build_site.py` from the `portfolio` folder.
You can also edit the HTML directly, but then the next rebuild overwrites those edits.

The CV source is `../portfolio/cv_general.tex`. Compile it with **LuaLaTeX** and copy
the PDF here as `cv.pdf`.
